# Contributing

Thank you for helping. Corrections to content are the most valuable contribution.

## Before you start

- Read `CONTENT-POLICY.md`. Every line of religious content must come from an approved source, unchanged, with its reference. Pull requests that add other sources, or text written by the contributor or generated by software, are closed.
- Content changes go in `content-src/` only. Run `python3 tools/build_content.py` and the tests before opening a pull request.

## Code

- Swift and SwiftUI for the app (iOS 17 and later). Python 3 for the content tools only; Python is not part of the app.
- Run the tests:

  ```bash
  python3 -m unittest discover -s tools/tests
  cd Packages/NasuhaCore && swift test
  ```

- Do not add third-party packages, analytics, ads or tracking.

2. the project owner may also publish your contribution as part of the official Nasuha app on the App Store, including a version that accepts optional tips.

## Reporting a content mistake

Open an issue with the ayah reference, what is wrong, and the source that shows the correct text. Mistake reports are answered within 7 days.
